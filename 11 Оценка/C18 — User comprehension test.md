# User comprehension test

## Вход

После редакции сложной инструкции есть возможность проверить её на 3 представителях аудитории.

## Ожидаемое решение

Рекомендовать ранний comprehension/usability test и фиксировать наблюдаемые проблемы, а не только readability score.

## Недопустимое решение

Объявить текст понятным по субъективной оценке редактора.

## Процедура теста

Запустить задачу без чтения этой карточки. Сохранить ответ. Затем сравнить с expected outcome и проверить provenance/semantic preservation отдельно.
