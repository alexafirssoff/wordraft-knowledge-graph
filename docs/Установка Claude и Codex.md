# Как подключить агента к Wordraft

Здесь описан способ для **Obsidian на компьютере**. Понадобятся Obsidian, Copilot V4 и доступ к выбранному агенту. Установка плагина не означает бесплатного доступа к моделям.

## Claude Code

1. Установите Claude Code официальным способом и выполните вход в свою учётную запись.
2. В Obsidian установите плагин Copilot. Откройте Copilot → Basic → Agents → Claude → Configure.
3. Выберите Auto-detect или укажите путь к `claude`. При необходимости нажмите Sign in.
4. Откройте Agent Chat. Убедитесь, что агент имеет доступ к вашему vault и запрашивает разрешение перед изменениями.

## Codex с аккаунтом ChatGPT

1. Откройте Copilot → Basic → Agents → Codex.
2. Установите адаптер Codex по инструкции Copilot (`codex-acp`) и выполните вход через поддерживаемый аккаунт.
3. Откройте Agent Chat, выберите Codex. Доступность зависит от вашего плана и ограничений аккаунта.
4. Проверьте, что запись в файлы vault требует вашего согласия.

Встроенный чат ChatGPT в браузере — отдельное приложение. **Этот способ подключает именно Codex внутри Obsidian**, а не веб-чат по API.

## Скиллы

Copilot → Skills → Your Skills должен показывать файлы из `copilot/skills`. Включите их для Claude или Codex. Если плагин использует другую папку, переместите копии по инструкции из `docs/Скиллы и лицензии.md`.

## Пробный запрос

> Прочитай AGENTS.md, выбери маршрут UX-copy и проверь фразу «Письмо отправлено». У меня нет подтверждения, что письмо действительно ушло. Какие утверждения здесь не подтверждены? Ответь со ссылками на применимые ID, не меняй файлы.

**Результат проверки:** агент не должен объявлять письмо отправленным без факта; при отсутствии подтверждения должен задать вопрос или предложить условный вариант. Ответ зависит от выбранной политики и сценария. Это не обещание конкретного вывода LLM.

Документация Copilot: https://docs.obsidiancopilot.com/ и https://docs.obsidiancopilot.com/agent-mode-and-tools/.
