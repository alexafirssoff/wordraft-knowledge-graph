# Проверка и редакторский аудит

Используйте для review, критического чтения, оценки готовности публикации, спорных правил и замечаний команде.

1. Получите сценарий, читателя, канал, факты и принятую проектную политику. Если факты отсутствуют, укажите это в выводе.
2. Пройдите `python -m wordraft route --task full_review` для нормативного аудита либо `--task review` для обычного. Для каждого найденного A убедитесь, что `current_status=active`, есть активный S и известна область применения.
3. Отделяйте **подтверждённое нарушение**, **риск фактической ошибки**, **стилевую рекомендацию** и **вопрос владельцу**. Внешние K/R — рекомендации и источники, не active A.
4. Проверяйте сохранение смысла: отрицание, условия, количественные значения, фактическое выполнение действия и обещания. Зафиксируйте противоречия в документах, не выбирайте автоматически победителя.
5. Верните короткий диагноз и таблицу «фрагмент → проблема → источник → действие». Если критичных проблем нет, напишите «оснований для обязательной правки не найдено».

Не ссылайтесь на узел лишь по заголовку; проверяйте цепочку источника по `explain`. Не читайте `11 Оценка` как подсказку в обычной задаче.
