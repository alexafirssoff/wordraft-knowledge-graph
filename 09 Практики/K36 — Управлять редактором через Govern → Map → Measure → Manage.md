# Управлять редактором через Govern → Map → Measure → Manage

## Рабочая практика

Для развития системы: зафиксировать governance/authority, описать контекст и риски, измерять качество/ошибки, затем управлять приоритетами и улучшениями; цикл повторять.

## Границы

Не превращать AI RMF в линейный чек-лист — это framework, который адаптируется к контексту.

## Статус

Это **advisory practice**, а не active canonical assertion. В ревью её можно использовать как «рекомендацию», но не как нарушение политики. При конфликте с active A действует [[J02 — Локальная активная норма сильнее advisory-практики]].
