# Wordraft · граф знаний редактора

**Редакционная политика, которую агент умеет находить, проверять и развивать.** Открывается в Obsidian, работает с Claude Code, Codex и другими агентами, поддерживающими Markdown и Agent Skills.

Внутри: структурированные правила и их источники, примеры, маршруты задач, процедуры, проверки и каталог внешних практик. Репозиторий содержит полный стартовый граф. Авторство и сведения о разрешении на использование редполитики указаны в [разделе о правах](NOTICE-CONTENT.md). Подключение к агентам зависит от установленной версии Obsidian, Copilot и Claude Code или Codex; автоматический end-to-end прогон этих связок остаётся отдельной проверкой.

## Первый запуск

1. Скачайте архив и распакуйте его. В Obsidian выберите **Открыть папку как хранилище** и укажите папку, в которой находится этот README.
2. Установите в Obsidian плагин **Copilot**: Настройки → Сторонние плагины → Обзор → Copilot → Установить → Включить. Это сторонний плагин; ознакомьтесь с разрешениями.
3. Откройте Настройки → Copilot → Basic → Agents. Выберите **Claude Code**, **Codex** или **opencode**. Подключение выполняется средствами Copilot и выбранного агента, не через наш ключ. Детали — в [инструкции](docs/Установка Claude и Codex.md).
4. В Copilot → Skills включите Wordraft-скиллы из `copilot/skills` для выбранного агента. Если они не появились, смотрите [раздел о скиллах](docs/Скиллы и лицензии.md).
5. Откройте [[Начните здесь]] и попросите агента: **«Проверь этот UX-текст по маршруту Wordraft. Приведи применимые ID и их источники. Не додумывай поведение продукта».**

> Для работы с локальной файловой системой через встроенного агента нужен настольный Obsidian. Обычный чат на сайте ChatGPT сам по себе не подключается к хранилищу Obsidian. Подключение ChatGPT-аккаунта здесь означает **Codex через Copilot Agent Chat**, при условии доступности Codex в аккаунте.

## Работа с графом

- **Редактировать:** выберите текст, задачу и редакционную политику; запросите проверку по маршруту Q.
- **Написать:** дайте аудиторию, канал, цель и подтверждённые факты, затем попросите написать без выдуманных свойств продукта.
- **Проверить источники:** попросите показать цепочку `A → S → I → F → V → D` и применимость к ситуации.
- **Добавить материал:** агент подготовит предложение, а вы утвердите изменения отдельно. Никто не имеет права автоматически включать внешние рекомендации как обязательные правила.

## Проверка установки

```bash
python -m pip install -e '.[test]'
python -m wordraft validate
python -m wordraft route --task ux_copy
python -m wordraft explain A02
python -m wordraft release-check --profile public
python -m pytest tests -q
```

Python 3.10+ нужен **для валидатора и безопасного пополнения**. Просматривать граф и использовать его как Markdown можно и без Python.

## Устройство

- `01 Источники` — документы D, версии V, исходные фрагменты F.
- `02 Утверждения` — локальные нормы A, каждая со статусом и областью применения.
- `03 Основания` — извлечения I и основания S.
- `04 Примеры`, `06 Процедуры`, `07 Маршруты`, `08 Внешние ресурсы`, `09 Практики`, `10 Решения`, `11 Оценка`, `12 OWASP` — соседние области графа.
- `copilot/skills` — агентские процессы: редактура, написание, ревью, работа с источниками и построение графа.
- `wordraft/` — детерминированные проверки и безопасное применение предложений.

## Источники

Граф основан на редакционной политике Людмилы Сарычевой [«Текст в Модульбанке»](https://docs.google.com/document/d/1c_2uP1PpiM12h1ee8egVXAoUCJ9mE9r68zMqrqmS8VA/edit?usp=sharing) (2016) с сохранением атрибуции, подтверждения автора со слов владельца репозитория и ссылок на редакционные и технические стандарты. Исходная редполитика действует **для своего контекста**, а не автоматически для каждого пользователя Wordraft. Скиллы `redaktura-skills` доступны отдельно: https://github.com/N1arko/redaktura-skills (CC BY 4.0).

**Данные пользователя остаются в его папке**, но подключённая облачная модель или внешние инструменты могут получать текст и его фрагменты. Проверяйте разрешения агентов и правила выбранного провайдера.
