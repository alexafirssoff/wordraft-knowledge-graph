# Триаж задачи и бриф

## Цель

Процедурный узел: определяет **когда и в каком порядке** применять знания. Он не создаёт языковую норму сам по себе.

## Шаги

1. Определить: написать, отредактировать, проверить, сократить, UX, post, promo, article, technical docs или knowledge update.
2. Извлечь читателя, площадку, цель, регистр, факты и ограничения.
3. Выбрать Q-route.
4. Спросить только то, без чего нельзя безопасно продолжить; не устраивать длинную анкету.

## Stop / escalation condition

Если тип задачи неясен, выбрать самый узкий правдоподобный route и явно назвать допущение.
