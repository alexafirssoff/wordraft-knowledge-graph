# Тестировать понимание, а не только грамотность

## Рабочая практика

Для важного content flow проверять, понимает ли целевая аудитория смысл и следующий шаг. Тестировать как можно раньше, когда материал уже достаточно оформлен для проверки.

## Границы

Автоматическая readability-метрика не заменяет user comprehension testing.

## Статус

Это **advisory practice**, а не active canonical assertion. В ревью её можно использовать как «рекомендацию», но не как нарушение политики. При конфликте с active A действует [[J02 — Локальная активная норма сильнее advisory-практики]].
