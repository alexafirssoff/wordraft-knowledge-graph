# Статья: бриф → фактура → форма → драматургия → оформление → самопроверка

## Рабочая практика

Статью строить вокруг полезного действия и фактуры: сначала понять читателя и опоры, затем выбрать форму/структуру и только потом писать черновик.

## Границы

Если есть только тема без опор, сначала собрать материал или явно отметить места, где он нужен.
