# Редактура с обоснованием

Используйте, когда пользователь просит сократить, переписать, улучшить или разобрать готовый текст на русском языке. Цель — улучшить задачу текста, а не увеличить число правок.

1. Прочитайте `AGENTS.md`; уточните читателя, место публикации, задачу, регистр и статус фактов.
2. Выполните `python -m wordraft route --task edit`, прочитайте последовательность P и применимые A. Для сомнительных правил выполните `explain Axx`, проверьте F и scope. Внешние K могут советовать, но не доказывают нарушение.
3. Идите проходами: задача и фактура → структура → тональность → предложение → слово → ритм → остаточные AI-штампы. Сохраняйте условия, отрицания, цифры, даты и границы обещаний.
4. Если данных мало, не домысливайте их; сформулируйте точный вопрос. Если текст корректен, оставьте без изменений.
5. Ответ: **готовая версия**, затем **важные изменения с основаниями** (3–7 максимум), затем **чего не хватило**, если применимо. При противоречии политик остановитесь и попросите владельца выбрать.

Не объявляйте стиль нарушением безопасности. Не применяйте специфическую редполитику Модульбанка к произвольной компании без заданной области.
