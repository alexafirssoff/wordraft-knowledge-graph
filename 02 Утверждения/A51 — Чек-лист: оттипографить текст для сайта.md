# Чек-лист: оттипографить текст для сайта

Если текст публикуется на сайте, оттипографить его; источник рекомендует Типограф Лебедева для тире, кавычек и неразрывных коротких предлогов.

## Где действует

Шаг 8 чек-листа; только для публикации на сайте.

## Основание в источнике

> Если публикуете текст на сайте, обязательно его потипографьте
