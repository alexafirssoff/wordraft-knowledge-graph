# Редакторская машина Wordraft v3

Эта версия превращает takeaway из графа норм в **editorial reasoning system**.

## Пять слоёв

1. **Normative knowledge** — существующие A/S/I/F/V/D: что считается действующей нормой и почему.
2. **Procedural graph** — P: когда и в каком порядке применять знания.
3. **Task routing** — Q: какой набор процедур нужен для статьи, поста, UX, docs, promo, полного аудита или knowledge update.
4. **External intelligence** — R и K: куда идти за best practices и какие advisory practices уже извлечены без превращения их в политику.
5. **Governance + evaluation** — J и C: precedence, preservation, security и regression tests.

## Runtime traversal

```text
brief / user text
      ↓
Q task route
      ↓
P procedures ─────→ active A ─→ S → I → F → V → D
      │
      ├────────────→ advisory K ─→ R external resources
      │
      └────────────→ J decisions (precedence / safety / preservation)
      ↓
P16 final preservation audit
```

Если локального знания недостаточно: P17 → P00 → relevant R. Новое повторно полезное знание: P18 → draft D/V/F/I/S/A → owner approval. URL сам по себе ничего не активирует.
