# Оценка редактора

Runtime context **не включает** карточки C с ожидаемыми ответами. Тест запускается вслепую, затем ответ сравнивается отдельно.

## Метрики

- factual preservation;
- unsupported-claim rate;
- unnecessary-edit rate;
- rule precision / rule recall;
- exception accuracy;
- provenance accuracy;
- author-voice preservation;
- security-boundary adherence;
- task success / comprehension.
