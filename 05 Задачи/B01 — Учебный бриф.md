# B01 — Учебный бриф

Все продуктовые обстоятельства ниже вымышлены для упражнения. Не являются условиями ВТБ.

- Режим: учебный пример с названием ВТБ.
- Канал: письмо клиенту, русский язык.
- Аудитория: предприниматели, подавшие заявку.
- Цель: подтвердить получение заявки и объяснить следующий шаг.
- Подтверждено для задачи: заявка получена; статус заявки можно посмотреть в личном кабинете; услуга пока не подключена.
- Неизвестно: срок подключения, стоимость, срок ответа, необходимость дополнительных документов.
- Термин задачи: РКО означает «расчётно-кассовое обслуживание»; для этой аудитории считать аббревиатуру незнакомой. Это условие учебного брифа, не утверждение из исходной редполитики.
- Формат: до 350 знаков с пробелами, без темы письма, с приветствием.

Текст для ревью:

> Здравствуйте! Ваша заявка на РКО получена! Подключим всё за пять минут. Статус заявки — в личном кабинете.
