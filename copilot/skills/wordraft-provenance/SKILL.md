# Проверка источников и зависимостей

Используйте, когда спрашивают «почему так», откуда взялось правило, кто подтвердил его, что изменилось и что зависит от утверждения.

1. Найдите конкретный идентификатор записи; запустите `python -m wordraft explain Axx`.
2. Прочитайте текст каждого звена A→S→I→F→V→D. Ссылка подтверждает существование записи, но не её смысл. Убедитесь в области действия, текущем статусе и неполноте графа.
3. При нескольких независимых поддержках отделите потерю одного источника от потери всех оснований. OUT/неподтверждённость не равнозначна логической ложности.
4. При противоречии покажите обе стороны, их версии, область и недостающую проверку; не решайте спор по дате или количеству цитат.
5. Для impact analysis обходите **только существующие явные ссылки** к текстам/решениям. Если граф не содержит связи с UI-строкой, её нельзя выдавать за найденную зависимость.

Ответ: утверждение → доступные основания → ограничения уверенности → затронутые связанные записи → необходимое решение владельца.
