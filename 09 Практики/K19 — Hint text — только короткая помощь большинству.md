# Hint text — только короткая помощь большинству

## Рабочая практика

Hint рядом с полем использовать для короткой информации, полезной большинству. Длинное объяснение выносить в основной content, чтобы не перегружать interaction и assistive technology.

## Границы

Не прятать критически важное условие только в hint.

## Статус

Это **advisory practice**, а не active canonical assertion. В ревью её можно использовать как «рекомендацию», но не как нарушение политики. При конфликте с active A действует [[J02 — Локальная активная норма сильнее advisory-практики]].
