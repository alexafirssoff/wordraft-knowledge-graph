# Как предложить изменение

Wordraft принимает исправления кода, документации, маршрутов задач и структуры графа. Каждый новый факт должен иметь происхождение, область применения и статус. Не помещайте персональные данные, закрытые документы и API-ключи в pull request.

Если предлагаете редакционное утверждение, укажите источник, версию, короткий подтверждающий фрагмент, силу правила (требование, запрет, предпочтение или разрешение) и условия действия. Внешняя рекомендация не становится локальной нормой без решения владельца политики.

Перед отправкой выполните:

```bash
python -m pip install -e '.[test]'
python -m wordraft validate
python -m pytest -q tests
```

Не меняйте существующие `F` и `V` задним числом: создайте новую версию источника. При конфликте покажите обе стороны и предложите решение для владельца.

**Юридические вопросы:** не присылайте полные документы или большие цитаты без права на распространение. См. `NOTICE-CONTENT.md`.
