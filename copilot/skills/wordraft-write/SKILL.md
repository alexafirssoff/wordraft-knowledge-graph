# Текст с нуля и проверка фактов

Используйте для статей, инструкций, писем, постов и промотекстов, когда пользователь просит написать текст с нуля.

1. Сначала сформулируйте бриф: цель и читатель, площадка, фактура, авторский голос, ограничения.
2. Выберите маршрут Q: `--task article`, `--task post`, `--task promo`, `--task docs` или `--task write`. Применяйте процедуры последовательно; по необходимости исследуйте внешние источники через P17, помечая непроверенное.
3. Сначала фактура, затем логика и структура, затем черновик. Запрещены выдуманные цифры, имена, сроки, кейсы, цитаты, продуктовые возможности и ложное утверждение о выполнении действий.
4. Финальный проход: смысл, обоснованность claims, словарь проекта, ясность, ритм, отсутствие шаблонных AI-оборотов. Для поста не превращайте живой текст в отчёт; для документации важнее точность и действия.
5. Отдайте итоговый текст, короткий список использованных оснований и только действительно необходимые вопросы. Локальная банковская политика не глобальна.

При установленном `redaktura-skills` можно дополнительно использовать соответствующий жанровый skill; Wordraft отвечает за provenance и локальные ограничения.
