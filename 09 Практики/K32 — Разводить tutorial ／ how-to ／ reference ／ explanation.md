# Разводить tutorial / how-to / reference / explanation

## Рабочая практика

Learning path, task recipe, factual reference и conceptual explanation требуют разных структур. Не смешивать их без причины.

## Границы

Cross-links между типами полезнее, чем один универсальный документ на все случаи.

## Статус

Это **advisory practice**, а не active canonical assertion. В ревью её можно использовать как «рекомендацию», но не как нарушение политики. При конфликте с active A действует [[J02 — Локальная активная норма сильнее advisory-практики]].
