# Не раскрывать наличие аккаунта

Нельзя различать формулировку ответа на запрос восстановления пароля по тому, существует ли аккаунт.

Это **source-backed candidate**: используется в учебном сценарии, но не становится active local policy для чужого продукта без подтверждения владельца.

Важно: для существующего аккаунта демонстрация явно задаёт факт отправки письма. Это условие **не выводится из OWASP**.
