# Genre pass: article, post, promo

## Цель

Процедурный узел: определяет **когда и в каком порядке** применять знания. Он не создаёт языковую норму сам по себе.

## Шаги

1. Для article: бриф → фактура → форма → структура → draft → self-check.
2. Для post: одна мысль → hook → body → final.
3. Для promo: audience/desire → offer → evidence → terms/next step.
4. Применить только ветку текущего жанра.

## Stop / escalation condition

Не смешивать “пост”, “статью” и “лендинг” в одну универсальную структуру.
