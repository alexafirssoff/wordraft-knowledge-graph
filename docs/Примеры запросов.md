# Примеры запросов

### Отредактировать

> Проверь текст по Wordraft. Контекст: [аудитория, канал, что происходит]. Прочитай AGENTS.md и выбери маршрут edit. Сначала проверь факты и смысл; не переписывай ради переписывания. Приведи применимые узлы и основания.

### Написать статью

> Напиши статью для [аудитория] о [тема]. Материалы: [ссылки / заметки]. Пройди маршрут article. Не выдумывай примеры, числа и цитаты; сначала спроси о недостающих фактах.

### Проверить UX

> Проверь текст интерфейса: [текст]. Сценарий: [действие пользователя]. Используй маршрут ux_copy, проверь обещания и security-условия. Сошлись на основания A→S→I→F.

### Добавить источник

> Оцени новый документ как источник для Wordraft. Сначала проверь лицензию и область действия, найди возможные конфликты. Подготовь JSON-предложение для команды propose; **не применяй** его без моего подтверждения.

### Найти зависимые тексты

> Изменилось утверждение Axx. Покажи связанный список утверждений, оснований и документов. Не заявляй о полном охвате текстов продукта, если связи с продуктовым контентом не сохранены.
