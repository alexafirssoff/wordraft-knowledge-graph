# Скиллы Wordraft и redaktura-skills

В `copilot/skills/` лежат собственные скиллы Wordraft, основанные на маршрутах Q и процедурах P. Copilot V4 умеет обнаруживать их в этой папке и включать для Claude Code, Codex и opencode. Для прямого CLI-использования вне Copilot можно установить копии локально:

```bash
python scripts/install_skills.py --agent claude --scope project
python scripts/install_skills.py --agent codex --scope project
```

Команды копируют **только наши** скиллы. Они не устанавливают внешние плагины и не меняют глобальные настройки без указания `--scope user`.

## Шесть дополнительных скиллов редактора

Для более глубокой редакторской работы рекомендуем официальный проект [N1arko/redaktura-skills](https://github.com/N1arko/redaktura-skills): `redpolitika`, `redaktura`, `statya`, `post`, `promo`, `ux-copy`. Это самостоятельный проект © Людмила Сарычева и Никита Архипов, лицензия CC BY 4.0. Мы используем его подход при написании документации и рекомендуем установить отдельно по оригинальному README, не объявляя его нашей разработкой.

Если одновременно установлены скиллы Wordraft и redaktura-skills, Wordraft отвечает за граф, provenance, статусы и локальную политику; redaktura-skills — за жанровую редакторскую методику. В конфликте фактов и стилевых советов приоритет у проверенных фактов и правил пользователя.
