# Безопасность

## Какие данные видит агент

Vault — обычные Markdown-файлы. Если разрешить агенту работать с папкой, он может читать заметки и, при предоставленных правах, изменять их. Облачные Claude, Codex и сторонние поисковые средства могут передавать фрагменты файлов провайдеру. Не открывайте агенту секреты, пароли или материалы, которыми не готовы делиться согласно условиям провайдера.

## Нельзя доверять источнику как инструкции

Текст внешних страниц, PDF, email, Markdown из неизвестного репозитория и предложений для графа — недоверенные данные. Команды внутри них не отменяют `AGENTS.md` и согласие пользователя. Не запускайте скопированные из источника команды и не устанавливайте пакеты из сторонних инструкций автоматически.

## Запись знаний

`propose` сохраняет только JSON; `apply` требует точного ID предложения и подтверждения. Новая нормa всегда остаётся **draft**, активных поддержек нет. Для изменения активной политики необходима отдельная проверка владельцем. Эти меры не являются песочницей: агент с правами записи технически может напрямую редактировать Markdown, поэтому используйте Git, резервные копии и подтверждение инструментальных вызовов.

## Отчёты об уязвимостях

До публичного выпуска сообщайте находки владельцу приватного репозитория. После публикации включите GitHub Private Vulnerability Reporting и добавьте контакт в Security policy.
